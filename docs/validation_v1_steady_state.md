# CIGRE-MV-PSCAD, version 1: steady-state validation

Date: 2026-09-04. Model generated by `scripts/build_cigre_mv.py` from
`data/cigre_mv_european_tb575.json`; validation by `scripts/validate_cigre_mv.py`.
Project: `pscad/CIGRE-MV-PSCAD/CIGRE_MV_PSCAD.pscx`. Run: 1.0 s at 50 us, phasors fitted
over 0.8-1.0 s. Numbers in `results/validation_cigre_mv.json` (plain reference) and
`results/validation_cigre_mv_bias.json` (reference loads scaled by the fixed-load bias).

## What the model contains

| Element | Implementation (all master library) |
|---|---|
| 110 kV grid | `source3R`, 5000 MVA, R/X 0.1 (0.2408 + j2.408 ohm); EMF constant 110.48 kV so that bus 0 sits at 110.0 kV, matching the brochure's slack definition |
| Transformers TR1, TR2 | `xfmr-3p2w`, 25 MVA, 110/20 kV, delta (HV) / star (LV), star neutral solidly grounded, Xl = 0.12 pu, copper loss 0.001 pu, no saturation. Fixed taps by secondary rated voltage: TR1 21.25 kV (+6.25 %), TR2 20.625 kV (+3.125 %) |
| Lines | 15 `newpi` coupled PI sections, R/L/C per metre from the brochure's positive and zero-sequence values, 50 Hz |
| Switches S1, S2, S3 | `breaker3` in series with segments 15, 6 and 11, state from constants (1 = open) |
| Loads | `fixed_load` per phase and per sector (residential, commercial/industrial), P and Q from the brochure's S and pf, both voltage exponents 0 (constant power), NCYC 10 |
| Bus connections | Node labels BUS_0 .. BUS_14; each bus has a `breakout` to phases with a line-ground voltmeter per phase |
| Recorded | 45 bus phase voltages, 6 transformer LV phase currents, grid P and Q; 53 channels |

Sign convention: the LV side leads the HV side by 30 degrees, as in the brochure's Table 9.6
(bus 1 at +23.66 degrees with bus 0 at 0). IEC "Dyn1" would be a 30 degree lag; users who
want that flip the transformer's "Delta lags or leads" setting.

## Result 1: agreement with a load flow built from the same data

pandapower 3.5.4, same data file, HV bus fixed at 110 kV, same taps. Reference loads scaled
by 1.0077 to remove the measured constant-power bias of the master-library load
(see `docs/fixed_load_test.md`).

| Bus | EMT kV L-L | pandapower kV | Error | EMT angle | pandapower angle |
|---|---|---|---|---|---|
| 0 | 110.004 | 110.000 | +0.004 % | 0.00 | 0.00 |
| 1 | 20.410 | 20.413 | -0.017 % | 22.96 | 22.96 |
| 3 | 19.225 | 19.224 | +0.005 % | 20.33 | 20.33 |
| 11 | 19.069 | 19.067 | +0.007 % | 19.98 | 19.99 |
| 12 | 19.984 | 19.988 | -0.016 % | 24.11 | 24.11 |
| 14 | 19.831 | 19.834 | -0.015 % | 24.03 | 24.03 |

Worst bus voltage error over all 15 buses: **0.017 %**. Worst angle error: 0.01 degrees.
Transformer LV currents: TR1 716.6 A (pandapower 716.3), TR2 615.9 A (616.5).
Phase-to-phase voltage unbalance in the EMT result: 0.02 %, i.e. balanced.

Without the bias scaling the worst error is 0.104 %, entirely attributable to the load
component drawing 0.77 % more than its setpoint.

## Result 2: agreement with the brochure's reference table (TB 575 Table 9.6)

| Bus | Brochure kV | EMT kV | Error |
|---|---|---|---|
| 1 | 20.52 | 20.41 | -0.54 % |
| 3 | 19.43 | 19.22 | -1.06 % |
| 11 | 19.29 | 19.07 | -1.15 % |
| 12 | 20.04 | 19.98 | -0.28 % |
| 14 | 19.88 | 19.83 | -0.25 % |

Worst error **1.15 %** at the feeder-1 end. This is the same discrepancy the pandapower
rebuild itself shows against the table (1.05 %), so it is a property of the published
data rather than of the EMT model: the brochure's authors evidently used slightly
different line impedances or load values than the rounded tables give. Angles agree in
sign and to within 1 degree. Transformer currents agree within 1.5 % (TR1) and 0.6 % (TR2).

## Assumptions the brochure does not fix

- Transformer magnetising branch and saturation: omitted (ideal core).
- Star neutral grounding: solid. Brochure gives no value.
- Zero-sequence impedance of the 110 kV equivalent: equal to positive sequence.
- Loads: constant power, balanced, no dynamics beyond the component's own release logic.
- Line model: lumped coupled PI, adequate below a few kHz for these lengths.
